---
name: Event input conventions
description: User-requested date controls and flexible-payment deadline presentation across LUDI.
---

Use a standard calendar widget for editable dates, except date of birth, which should remain unchanged.

Present flexible-payment authorisation opening and collection deadlines as relative offsets with separate days and hours inputs: before event start for opening, after event end for collection.

**Why:** The user requested calendar-based date entry and relative day/hour payment settings instead of absolute deadline dates.

**How to apply:** Keep these conventions consistent in LUDI's web and mobile create/edit forms and any future date-entry controls. Changing event dates or times should retain the chosen offsets.
